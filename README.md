## ✨ Features

- 🎨 **Theme Engine:** Preconfigured dynamic themes synced perfectly across stats, borders, and SVGs.
- ⚡ **Real-time Live Preview:** See exactly what your README will look like (dark/light mode aware) as you build it.
- 🚀 **Interactive Charts & SVGs:** Natively embeddable Developer Radars, Retro Terminals, 3D Isometric Git Activity, and Top Languages.
- 📊 **Dynamic Widgets:** Seamless integrations with GitHub Readme Stats, Streak Stats, Top Languages, and Skill Icons.
- 💻 **Raw Markdown Export:** Clean, standards-compliant, semantic HTML-flavored markdown that works flawlessly anywhere.

## 🚀 Quick Start

To run Vectomark locally and start developing or generating your own profiles:

### 1. Clone the repository
```bash
git clone https://github.com/hamzarihani/vectomark.git
cd vectomark
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. The studio is located at `/builder`.
